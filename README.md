# Bad Advice Inc.

A one-page health awareness satire built with HTML and CSS. It jokingly praises unhealthy habits, then corrects each claim. The Gmail address and phone number in the contact section are fictional props.

## Open locally

Open `index.html` in a browser. Keep the `images` folder and `style.css` beside it.

## Project files

- `index.html` — page content
- `style.css` — responsive layout and styling
- `images/` — original SVG illustrations

This site is a parody, not medical advice. For personal health concerns, talk to a qualified healthcare professional.
